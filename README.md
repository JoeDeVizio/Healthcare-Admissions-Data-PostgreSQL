Healthcare Admissions Data Project with PostgreSQL.

Project Overview
My first sql project. This project focuses on cleaning, standardizing, and validating a healthcare admissions dataset using PostgreSQL. 
The goal was to improve data quality, identify inconsistencies, and prepare the dataset for reliable analysis.

Tools Used
PostgreSQL
pgAdmin 4
SQL

Data Cleaning Tasks
Identified and handled missing values.
Standardized inconsistent gender and admission type values.
Identified and investigated duplicate records.
Cleaned inconsistent admission date formats.
Identified invalid and unusual age values.
Used SQL queries to validate data quality.
